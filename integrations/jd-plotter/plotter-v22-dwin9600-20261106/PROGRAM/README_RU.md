# Пульт плоттера

## Запуск

На этом ноутбуке откройте `START.cmd` уровнем выше. Он использует текущий
профиль MKS V2.2. `PROGRAM/START.cmd` предназначен для отдельной установки.

1. Распакуйте весь ZIP в обычную папку. Сохраните папку `OFFLINE_WHEELS` рядом с `PROGRAM`.
2. На другом компьютере установите Windows Python 3.11–3.14 x64 с компонентом Tk. Затем откройте `PROGRAM/INSTALL.cmd`: он создаст локальное окружение и установит три базовые библиотеки из вложенных файлов без интернета.
3. Запускайте `PROGRAM/START.cmd`. Изначально выбран **DEMO**, поэтому открытие приложения не подключает моторы. Профиль платы по умолчанию — MKS DLC32 / FluidNC; Uno / GRBL выбирается в списке.
4. Для камеры, сканирования и обводки PNG/JPG выполните `INSTALL_CAMERA.cmd` при наличии интернета. Без этих дополнительных библиотек основной пульт, SVG и редактор текста работают.

Камера, ручной редактор и окно подключения DWIN находятся в «Инструментах».
В «Инструменты → Настройки» доступны профиль платы, тесты ручки и журнал.

## Что сохранено

- Подключение Uno/GRBL и MKS DLC32/FluidNC, включая сеть, существующие проверки соединения, DWIN и его сетевой канал.
- Кнопки перемещения, длина шага, скорость в процентах, удержание моторов, два угла листа, тестовый рисунок, импорт SVG, предпросмотр и рисование.
- Соленоидный подъём пера и его настройки. Подтверждения реле и физический ноль со старого компьютера не перенесены.
- **Редактор**: печатный русский/латинский текст, переносы в текстовом блоке, несколько объектов, выбор мышью, изменение текста выбранного объекта, масштаб, угол, сдвиг, ширина и отражения.
- Прямоугольники, эллипсы, треугольники, линейки, образец проверки точности, сокращение переходов пера.
- Отмена/повтор, сохранение редактируемых проектов, SVG, автокопии и фиксированные шаблоны.
- **Рисунок по образцу**: локальное открытие изображения, поиск образца в Wikimedia Commons по нажатию кнопки, обрезка и выбор главного объекта, настройка детализации, штриховки и лимитов, сравнение обводки с оригиналом. Распознавание и обводка здесь выполняются обычными алгоритмами.
- Камера/сканер: сетевой поток, калибровка, границы бумаги, проходы сканирования и обработка изображения после установки дополнительных библиотек.

Ручной редактор работает отдельно. «Помощник» использует Codex через ваш
вход ChatGPT. Глубина ответа выбирается по запросу. Распознанный голос
попадает в поле ввода для проверки перед отправкой. Для отдельной установки
диктовки есть `INSTALL_VOICE.cmd`. Команда DWIN №17 открывает ручной редактор.

## Рисунок и лист

Для рисования подключитесь к нужной плате и заново задайте верхний левый и нижний правый углы листа. Изменение эскиза и запуск движения — разные действия: редактор меняет линии, а рисование запускается в основном пульте.

Редактор можно открыть без оборудования: он создаёт пробный лист A4. Размер этого листа меняется на вкладке «Проект» и не является калибровкой станка. Если уже сохранён физический ноль, для изменения пробного размера сначала сбросьте его в пульте. Проекты другого размера открывайте после задания такого же пробного размера.

Новая надпись или фигура сначала появляется на предпросмотре. Кнопка «Применить к эскизу» подтверждает изменение. Список над предпросмотром и нажатие на линии выбирают один объект; «Вся композиция» применяет преобразование ко всем. Изменения, выходящие за границы листа, отклоняются.

Для старых работ используйте «Открыть проект»: четыре сохранённых проекта находятся в `EXAMPLES/SAVED_PROJECTS`. Они включены как примеры, без автоматического восстановления состояния станка. Исходные образцы SVG лежат в корне программы, дополнительные интернет-образцы — в `internet_samples`.

## Установка и данные

Базовые зависимости: pyserial 3.5, svgelements 1.9.6, PyYAML 6.0.3. Пакеты для камеры указаны отдельно в `requirements-camera.txt`; они совпадают с установленными в проверяемой исходной версии.

Настройки выбранной платы, реле, шаблоны и автокопии сохраняются в папке
`data`. Диагностика соединения находится в `data/serial-diagnostics`,
журнал кнопок и остановок DWIN — в `data/diagnostics/dwin-events.jsonl`.

Прошивки и аппаратные модели находятся в соседних папках общего ZIP. Запуск пульта сам по себе не прошивает плату. Аппаратная проверка текущей сборки в ходе упаковки не выполнялась.
