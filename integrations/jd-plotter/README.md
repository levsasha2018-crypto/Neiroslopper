# JD Plotter DWIN UI 6

Отдельная сборка для MKS DLC32 V2.2 и DWIN 800 × 480. Ветка содержит пульт, интерфейс экрана и исходники FluidNC для образа panel6.

- В папке `plotter-v22-dwin9600-20261106` запустите `PROGRAM/INSTALL.cmd`, затем `START.cmd`. Пульт проверяет профиль MKS и ищет контроллер в локальной сети. Голосовой ввод и камера устанавливаются дополнительными скриптами в `PROGRAM`.
- Для DWIN скопируйте папку `dwin-assistant-20261108/DWIN_SET` на SD и загрузите её при выключенном питании дисплея. Интерфейс UI 6 использует таблицу страниц DGUS для динамических элементов. Файлы проверены программно, отображение UI 6 на физической панели ещё не подтверждено.
- Образ приложения MKS расположен в `firmware/pending-panel6/firmware-panel6.bin` внутри папки пульта. Профиль платы находится рядом в `firmware/jd_v22_dwin9600.yaml`. В `firmware/source` приложены исходники, файлы сборки и лицензия FluidNC. Сборка из исходников выполняется командой `pio run -e wifi` в этой папке.
- Для пересборки UI укажите путь к `ICLGenerator.dll` официального редактора DGUS в переменной `DWIN_ICL_GENERATOR`, путь к `DejaVuSansMono.ttf` в `DWIN_DEJAVU_FONT` и запустите `python dwin-assistant-20261108/build_release.py` с установленным Pillow и PowerShell 7.

[Обновление рисования и настройки скорости](plotter-v22-dwin9600-20261106/MOTION_UPDATE_RU.md).
